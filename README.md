# Kibo.ua

Навчальний проєкт з дисципліни «Веб-орієнтована розробка програмного забезпечення» (НН ІПСА, КПІ ім. Ігоря Сікорського).
Лабораторна робота №2: створення структури веб-проєкту.

Сайт для продажу готових термосумок зі складу та індивідуального пошиття через онлайн-конструктор. Ідея, кольори, шрифти та карта сайту взяті з лабораторної роботи №1.

## Запуск

Збірка не потрібна, достатньо відкрити `index.html` у браузері. Шрифти (Inter, Rubik, Fira Sans) підключаються з Google Fonts.

## Що далі

Бекенд (PHP + MySQL), кошик, особистий кабінет і англійська версія будуть у наступних роботах.

## Лабораторна робота №3: CSS та адаптивність

У цій лабораторній роботі реалізовано:
- **Модульна структура CSS:** стилі розділені на файли `base.css`, `layout.css`, `components.css` та об'єднані в `style.css` за допомогою директиви `@import`.
- **Сучасні макети:** для побудови сіток та шапки використано технології **CSS Grid** та **Flexbox**.
- **Адаптивний дизайн:** додано медіазапити (`@media`) для коректного відображення на планшетах і мобільних телефонах, а також реалізовано інтерактивне бургер-меню за допомогою JavaScript.
- **Клієнтська валідація:** налаштовано перевірку введених даних у формах (зокрема для полів телефону) з використанням HTML5-атрибутів та CSS-стилів для помилок.

## Лабораторна робота №4. Основи JavaScript

У межах лабораторної роботи реалізовано інтерактивну функціональність вебсайту Kibo.ua за допомогою JavaScript.

### Реалізовані функції
- Динамічна зміна стилів HTML-елементів.
- Додавання нових елементів до сторінок.
- Автоматичне відображення поточної дати у футері.
- Акордеон «Показати більше».
- Перемикання кольорової теми сайту.
- Підсвічування пунктів навігаційного меню.
- Зміна розміру шрифту клавішами ArrowUp та ArrowDown.
- Клієнтська валідація контактної форми.
- Збереження обраної теми в LocalStorage.

### Використані технології
- DOM — пошук, створення та модифікація HTML-елементів.
- Events — обробка подій click, mouseenter, mouseleave, keydown та submit.
- Validation — перевірка введених даних і виведення повідомлень про помилки.
- LocalStorage — збереження налаштувань користувача.

Основна JavaScript-функціональність реалізована у файлі `js/main.js`.
